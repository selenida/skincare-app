# Skincare

A personal, single-user PWA for tracking a nightly skincare routine with adaptive
retinoid pacing. No accounts, no notifications, no analytics. All personal data
lives in a separate private repository; this repo is only the app shell.

Built with plain HTML/CSS/JS — no build step, no dependencies.

- `index.html` + `js/` + `css/` — the app
- `tests.html` — engine test suite, runs in the browser
- `sw.js` + `manifest.json` — PWA install & offline support
